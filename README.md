# Phone Shell

«Телефон в телефоне»: рабочий стол, на котором сайты (банки и т.п.) выглядят как приложения.
Чистая Java, без библиотек — APK около 100–200 КБ.

## Как получить APK (без Android Studio)

1. Создайте **приватный** репозиторий на GitHub и загрузите туда содержимое этой папки
   (веб-интерфейс GitHub → Add file → Upload files; папку `.github` тоже загрузите).
2. Вкладка **Actions** → `build-apk` → Run workflow (или просто сделайте commit — запустится само).
3. Через ~3 минуты откройте завершённый запуск → **Artifacts → PhoneShell-apk** → скачайте, установите
   (разрешите установку из неизвестных источников).

Локально: `bash get_certs.sh && gradle :app:assembleRelease` → `app/build/outputs/apk/release/`.

> Подпись: `release.jks` лежит в репозитории (пароль `phoneshell`) — только для личной установки.
> Держите репозиторий приватным. Обновления ставятся поверх, пока ключ тот же.

## Возможности

- **Рабочий стол** с часами, сеткой «приложений» и док-панелью; долгое нажатие на иконку — открыть / изменить / обновить иконку / удалить.
- **Иконки** подтягиваются сами (apple-touch-icon → favicon), название — из `<title>`. Можно выбрать свою картинку из файла.
- **Переключение как в телефоне**: кнопки ◀ ● ■ внизу. ■ — список открытых приложений с миниатюрами, ✕ закрывает. Открытые сайты не теряют состояние (до 8 окон).
- **Корневой сертификат** действует только внутри приложения, системное хранилище не трогается:
  - встроенный (Минцифры) — скачивается при сборке `get_certs.sh`, применяется ко всем запросам приложения;
  - **📜 Сертификаты → Импортировать** — любой `.crt/.pem/.cer` без пересборки (применяется к сайтам из вашего списка, для главной страницы).
- **Сейф 🔐** — логины и карты. AES-256-GCM, ключ из мастер-пароля (PBKDF2-SHA256, 150 000 итераций), мастер-пароль нигде не хранится. Автоблокировка через 5 минут в фоне.
  - Кнопка 🔑 в открытом сайте подставляет логин/пароль или данные карты. Если домен записи не совпадает с открытой страницей — спросит подтверждение (защита от фишинга).
  - Копирование секрета в буфер очищается через 30 секунд.
- **Экспорт/импорт**: список сайтов (JSON, с иконками) и сейф (зашифрованный файл; при импорте нужен его мастер-пароль, записи объединяются без дублей).
- Защита от скриншотов включена по умолчанию (меню ⋮ → переключатель).

## Блокировщик рекламы

uBlock Origin — расширение браузера, в Android WebView расширения не работают, поэтому встроен его аналог:
домены из публичных списков (EasyList, RuAdList, uAssets; `get_lists.sh` собирает их при сборке) блокируются
на уровне запросов + скрываются типовые рекламные блоки. Включается галочкой «Блокировать рекламу» у каждого сайта
(по умолчанию вкл). Домены самих сохранённых сайтов никогда не блокируются, EasyPrivacy не используется,
чтобы не ломать антифрод банков. Фильтры вида `##селектор` и сложные правила uBO не поддерживаются.

## Маскировка под калькулятор

Меню ⋮ → «Маскировка под калькулятор: включить» → задайте код (4–12 цифр). После этого приложение называется
«Калькулятор», открывается рабочим калькулятором (дизайн Material, не iOS), а чтобы попасть внутрь, наберите код и нажмите «=».
Возврат в калькулятор: кнопка «назад» на рабочем столе, через 30 секунд в фоне, либо меню → «Свернуть в калькулятор».
Код хранится в виде хеша; это маскировка от посторонних глаз, а данные защищает мастер-пароль сейфа.
Название и иконку можно поменять в `AndroidManifest.xml` / `res/drawable/ic_launcher.xml`.

## Ограничения (честно)

- Сертификат из `res/raw` доверяется **всем** сайтам внутри приложения, а не только банкам. Пользуйтесь приложением для нужных сайтов.
- У всех сайтов общий cookie-хранилище WebView (раздельных профилей в WebView нет).
- Подстановка работает в основной странице; поля внутри платёжных iframe могут не заполниться.
- Скачивание файлов открывается во внешнем приложении, сессия не передаётся.
- Банковские приложения с привязкой к SMS/push/биометрии/антифродом могут вести себя иначе, чем нативные; часть банков блокирует веб-версию.
- Сертификаты с ГОСТ-алгоритмами WebView не поддерживает (RSA-корень Минцифры — поддерживает).
- Забытый мастер-пароль восстановить нельзя.
